# Crossed Belt Drive page notes

The initial Brown 002 editorial copy is based on movement 2 of Henry T. Brown's *507 Mechanical Movements* as represented by the current online transcription at https://507movements.com/mm_002.html.

Important modeling boundary: the live Atlas model on the canonical Crossed Belt Drive page represents the basic two-pulley crossed-belt principle. Brown's description also discusses a three-pulley fast/loose arrangement using both open and crossed belts to reverse a driven shaft without reversing the driver; that arrangement is treated as collection/application context rather than as something the two-pulley model simulates.

This file is temporary editorial provenance until the canonical source/claim schema from #8/#22 is implemented.
